# NP POWER TECH SOLAR

Complete solar business platform — public website, lead generation, CRM, quotations, orders, payments, installation tracking, customer portal, technician management, warranty, AMC, service requests, admin panel, analytics, and marketing attribution.

## Tech Stack

- **Frontend:** Python + NiceGUI
- **Backend:** Node.js + Express
- **Database:** PostgreSQL
- **Cache / Queue:** Redis
- **Reverse Proxy:** Nginx or Caddy
- **File Storage:** S3-compatible object storage (production) / local storage (development)
